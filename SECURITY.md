# Security Policy

## Supported Versions

Only the latest version of BotLens is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within BotLens, please send an e-mail to security@iamjarl.com. All security vulnerabilities will be promptly addressed.
