# Contributing to BotLens

First off, thank you for considering contributing to BotLens! It's people like you that make the AI-native web a better place.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issues tracker.
- Describe the bug and include steps to reproduce.
- Mention your browser version and OS.

### Suggesting Enhancements
- Open a new issue with a clear title and description.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code follows the **IAMJARL Design System**.
5. Issue that pull request!

## Design System
BotLens follows the [IAMJARL Design System](https://github.com/JarlLyng/iamjarl-design). Please use the provided `tokens.css` and Phosphor icons for any UI changes.
